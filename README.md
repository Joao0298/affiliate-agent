# Affiliate Agent

Agente de IA para descoberta, análise e criação de conteúdo para produtos de afiliados.

## Fluxo
1. Descobrir produtos em fontes autorizadas.
2. Coletar preço, avaliação, comissão e URL de afiliado.
3. Calcular oportunidade.
4. Gerar roteiro, legenda e CTA.
5. Enviar para aprovação humana.

## Regra importante
O agente não publica nem inventa links de afiliado automaticamente sem uma fonte/API autorizada.
